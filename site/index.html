# Champion Tier Win rate Pick rate Ban rate Presence Games

Pick a champion to see its synergies and counters.

Win rates shown are raw. Tiers, synergies and counters use smoothed rates (pulled toward average when there are few games) so small samples don't dominate. Synergy = how much better a pair does together than expected from each champion alone. Counter = how much the champion's win rate changes when facing that opponent.
